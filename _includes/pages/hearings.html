{% if es %}Reglas del D65 para las audiencias públicas{% else %}D65 public hearing guidelines{% endif %}
2

{% if es %}Habla por ti{% else %}Speak for yourself{% endif %}

{% if es %}Tienes tres minutos y puedes hablar una vez por audiencia. No puedes ceder tu tiempo ni hablar en nombre de otros, así que trae a tus vecinos y que cada uno hable también.{% else %}You get three minutes, and you can speak once per hearing. You can't give your time away or speak on behalf of others, so bring your neighbors and have each of them speak too.{% endif %}

3

{% if es %}Di quién eres{% else %}Say who you are{% endif %}

{% if es %}Madre, padre, maestro, vecino, dueño de un negocio. La junta necesita escuchar sobre todo a residentes que no tienen hijos en una escuela del D65.{% else %}Parent, teacher, neighbor, business owner. The board especially needs to hear from residents with no child in a D65 school.{% endif %}

{% if es %}Qué decir{% else %}What to say{% endif %}

{% if es %}Tu historia, más uno de estos tres puntos.{% else %}Your story, plus one of these three points.{% endif %}

{% if es %}Votar NO no es votar contra el cambio. Es decir sí a un plan más inteligente y sostenible que protege a los estudiantes, respeta el dinero de los contribuyentes y pone la educación primero. Elige el punto que sea verdad para ti y dilo con tus propias palabras.{% else %}Voting NO isn't a vote against change. It's a yes for a smarter, more sustainable plan that protects students, respects taxpayers' money and puts education first. Pick the point that is true for you and say it in your own words.{% endif %}

{% if es %}El presupuesto{% else %}The budget{% endif %}

{% if es %}Responsabilidad fiscal es agotar primero las demás palancas.{% else %}Fiscal responsibility means exhausting other levers first.{% endif %}

{% if es %}Cerrar una escuela el año pasado no nos habría evitado llegar aquí, y cerrar dos ahora tampoco.{% else %}Closing a school last year wouldn't have kept us from being here today, and closing two now won't either.{% endif %}

{% if es %}Vender Kingsley y Bessie Rhodes, cerrar los distritos TIF que vencen y hacer los recortes que no cierran escuelas.{% else %}Sell Kingsley and Bessie Rhodes, use available Debt Service Fund revenue to help pay the Foster debt, and make targeted central office cuts.{% endif %}

{% if es %}Cerrar Dewey y Lincolnwood solo nos da un año.{% else %}Closing Dewey and Lincolnwood buys us one year.{% endif %}

{% if es %}Equidad{% else %}Equity{% endif %}

{% if es %}Nuestros estudiantes más vulnerables merecen protección.{% else %}Require a complete transition plan before any vote.{% endif %}

{% if es %}Las familias de inmersión bilingüe, los estudiantes de STEP con autismo y los estudiantes con IEP y planes 504 son los más afectados.{% else %}Two-Way Immersion families, STEP students with autism, and students with IEPs and 504s carry the most.{% endif %}

{% if es %}La equidad debe demostrarse antes de un voto de cierre, no después.{% else %}Before voting to close any school, the District must present a finalized, fully resourced transition plan for these students. Students who have already been relocated must not be displaced again.{% endif %}

{% if es %}Si esta es tu familia, tu historia es lo más poderoso que escuchará la junta.{% else %}If this is your family, your story is the most powerful thing the board will hear.{% endif %}

{% if es %}Toda nuestra comunidad{% else %}Our whole community{% endif %}

{% if es %}La visión debe ir antes que los votos de cierre.{% else %}Vision should come before closure votes.{% endif %}

{% if es %}El D65 necesita un referéndum pase lo que pase, y cerrar escuelas lo hace más difícil de aprobar.{% else %}D65 needs a referendum no matter what, and closing schools makes it harder to pass.{% endif %}

{% if es %}Evanston tiene un historial comprobado de aprobar referendos, pero los votantes necesitan ver una hoja de ruta antes de que se les pida invertir.{% else %}Evanston has a proven record of passing referenda, but voters need to see a roadmap before they are asked to invest.{% endif %}

{% if es %}No hay que apresurar las decisiones más grandes antes de que haya una superintendencia permanente.{% else %}Don't push through the biggest decisions before a permanent superintendent is in place.{% endif %}
